unimpeccable.

an agent skill. anti-design as a discipline. authored chaos, not slop.

anti design

the five laws.

1.
chaos must be authored. if you can't justify the break, fix it. random is not radical.
2.
structure carries the load. brutalism underneath. memphis on top. without structure you have soup.
3.
illegibility is rationed. one carson moment per long page. more, and meaning evaporates.
4.
the floor is functional. decoration can be illegible. navigation cannot. forms cannot. cruelty is not the point.
5.
the enemy is the average. if your output could ship on a y combinator landing page, you failed. start over.

the enemy.

  • centered hero with subtle gradient.
  • "get started →" with a chevron.
  • inter at 14 / 24, line-height 1.5.
  • rounded-2xl + shadow-sm.
  • the three-column feature grid.
  • purple. specifically #8b5cf6.
  • "trusted by" logo strip in grayscale.
  • whitespace described as "breathing".
  • dark mode that is the light mode inverted.

nine schools.

lacquer
the house style. memphis palette over brutalist load-bearing structure, with rationed carson moments and a zine texture layer.
memphis
sottsass. milano. 1981. clashing laminate, squiggle, dot grid, terrazzo. asymmetric forms. sincere kitsch.
geocities
1995 to 2002. personal homepages, fan sites, hobby shrines. tiled patterned backgrounds, animated GIFs, frames, comic sans, hit counters. anti-design by innocence, not refusal.
carson / ray gun
david carson, 1990s. broken type. overlap. mid-word break. emotional impact over legibility. illegibility as message.
web brutalism
raw html. system fonts. default blue links. no style block. the page recedes so the content shows.
neubrutalism
2020s. hard borders, hard offset shadows, zero radius, acid color. been laundered into a tailwind preset. vary borders, vary shadows, escape the template.
zine / diy
photocopied. stapled. handed to you. ransom-note headlines. typewriter body. halftone photos. visible production marks.
y2k / dirtstyle
1998 to 2003. chrome. lens flare. hud overlays. designers republic. hardest school. pick a year. channel an artifact. do not nostalgia-meme.
acid graphics
2018 to present. roettinger, tom galle. chromatic aberration. 3D extruded type. aggressive mesh gradients. club poster energy. NOT the laundered web3 version. monospace as workhorse. ugly on purpose.

install.

one line. via skills.sh.

npx skills add BennettPhil/unimpeccable

then invoke.

/unimpeccable:spawn "a landing page for my band that argues with itself"

or lock a school first.

/unimpeccable:pick-school memphis
/unimpeccable:spawn "a poster site for a basement noise show"

nine commands.

commandwhat it does
pick-schoollock the school for the session. all subsequent work uses it.
spawnbuild a full anti-design page from a brief. runs the four-layer loop.
ruintake a polished page and break it. preserve every functional surface.
shredlayout-only fragmentation. four authorized grid breaks. no type or palette changes.
clashgenerate a discordant palette in the locked school. 3 to 5 acid hues plus black plus paper-white.
typecastpick the 2-font system from system fonts only. set the scale.
downgradereplace impeccable defaults with anti-design counterparts in place.
auditscan for polish tells and slop tells. report counts and locations. do not modify.
manifestogenerate anti-marketing copy in the skill's voice.
