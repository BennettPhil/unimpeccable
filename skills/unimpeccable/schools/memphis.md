# Memphis

founded by Ettore Sottsass in Milano, 1981. dissolved 1988. seven years of post-modern revolt against modernist sobriety. laminate furniture, kitsch pattern, clashing geometric joy.

Memphis was not a design "style." it was an argument against the idea that good design is restrained. it lost commercially. it won culturally.

## VISUAL MARKERS

- bold acid colors on plastic laminate surfaces
- geometric pattern fills: squiggle, dot, triangle, hatch, terrazzo
- asymmetric forms — never centered, never balanced
- "totem" stacking — objects built from incompatible volumes
- conscious kitsch — references to 1950s diner, B-movie sci-fi, ancient ornament
- material lies: plastic that pretends to be marble, marble that pretends to be cake

## MOTIFS

the Memphis vocabulary. each is a specific shape, drawn the same way.

- **squiggle (Bacterio)** — a 4–6 hump line, 3px stroke, ends in a tiny circle. usually in black or cobalt.
- **dot grid (Polka)** — 5×5 or 7×7 grid of solid circles, two alternating colors, ~8px dots, 24px spacing.
- **terrazzo (Schegge)** — irregular polygon shards in 3–4 colors, scattered in a contained zone.
- **diagonal hatch** — 2px parallel lines at 45°, 6px spacing.
- **triangle / circle / squiggle** — single floating shape in a color block corner, clipped by the block edge.

implement as inline SVG, never as images.

## RULES SPECIFIC TO THIS SCHOOL

- 2–3 motifs per section. NOT 8. NOT 1.
- color blocks are the primary structural element — sections are stacks of color rectangles
- Memphis is NOT brutalist on its own. add brutalist scaffolding (hard borders, zero radius) when you want a Lacquer-style page. pure Memphis is softer, more playful, more 1981.
- pure Memphis can use slightly different palette deployment: ALL the colors on ONE page, not the restrained 3-acid deployment of Lacquer.
- type pairing: keep Lacquer's Times/Arial Black combo. Memphis is about COLOR and PATTERN, not typography per se.
- shadows: pure Memphis didn't have web-style shadows. use color-blocks-behind-elements instead of box-shadow. rotated 2–4°.

## WHAT MEMPHIS IS NOT

- not "fun startup branding" (Slack-era reflex with squiggles and bright colors but tasteful spacing — that's Memphis-laundered-for-saas)
- not "ironic 80s nostalgia." Memphis was sincere. it MEANT it.
- not maximalism — Memphis is busy in zones, calm in others. selective.
- not pastel. Memphis colors are saturated, almost garish. that's the point.

## REFERENCES (NAMED ARTIFACTS)

if the user wants something specific:
- **Carlton bookcase (Sottsass, 1981)** — totem stacking, bright color blocks, asymmetric
- **Casablanca sideboard (Sottsass, 1981)** — terrazzo laminate, geometric, plastic
- **Bel Air chair (Peter Shire, 1982)** — geometric shapes as furniture parts, mismatched
- **Bacterio pattern (Sottsass, 1978)** — the squiggle pattern, predates Memphis but defines it

## SELF-CHECK FOR PURE MEMPHIS

- is the page built from stacks of color blocks?
- are there 2–3 motifs per section, from the Memphis vocabulary?
- is the palette set A or set C, deployed fully (not just 3 acids)?
- are color blocks rotated 2–4° behind elements instead of using soft shadows?
- did I keep brutalist sharpness OR did I let it be softer / more playful (both are valid pure Memphis — pick one)?
