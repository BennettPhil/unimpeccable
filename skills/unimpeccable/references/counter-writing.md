# counter-writing

words on the page are part of the design. impeccable writes "delightful microcopy." we write **fragments, refusals, manifestos.**

## THE VOICE

- lowercase by default
- ALL CAPS for emphasis bursts only (one to three words at a time)
- fragments are sentences. so are imperatives.
- periods where they don't belong.
- no em-dashes ("—"). use line breaks.
- no ellipses ("...") unless deliberately used to trail off menacingly
- no emoji. ever. (not even sparingly. not even ironically.)
- no exclamation marks except in declared parody
- no semicolons. write two sentences.

## THE BAN LIST (PHRASES)

these phrases do not appear in unimpeccable copy. ever.

- "Get started"
- "Learn more"
- "Discover"
- "Explore"
- "Sign up free"
- "Trusted by"
- "Built for"
- "Delightful"
- "Beautiful"
- "Powerful"
- "Seamless"
- "Effortless"
- "Modern"
- "Cutting-edge"
- "Reimagined"
- "Game-changing"
- "Best-in-class"
- "Robust"
- "Scalable"
- "World-class"
- "Premier"
- "Loved by"
- "Join thousands of"
- "From idea to launch"

if a brief asks for any of the above, replace with a refusal, an imperative, or a manifesto fragment. flag the substitution.

## THE REPLACEMENT TABLE

| saas reflex | unimpeccable replacement |
|---|---|
| Get started | `START.` or `BEGIN.` or `NOW.` |
| Learn more | `WHY.` or `MORE.` or `KEEP READING.` |
| Sign up | `JOIN.` or `IN.` |
| Log in | `RETURN.` or `BACK.` |
| Submit | `SEND.` or `GO.` |
| Cancel | `NO.` or `LEAVE.` |
| Delete | `KILL.` or `BURN.` |
| Save | `KEEP.` |
| Download | `TAKE IT.` |
| Buy / Purchase | `PAY.` |
| Continue | `NEXT.` |
| Back | `BACK.` (this one's fine. don't be precious.) |
| Loading... | `WAIT.` |
| Error | `WRONG.` |
| Success | `DONE.` |
| Forgot password? | `LOST IT?` |
| Read documentation | `THE BOOK.` |
| Pricing | `WHAT IT COSTS.` |
| Contact us | `FIND US.` |
| About | `WHO.` or `US.` |

## HEADLINES

three patterns to reach for. mix freely:

### 1. THE REFUSAL

> we will not do that.
> stop doing that.
> nobody asked.

### 2. THE DECLARATION

> THIS IS THE FIRE.
> WE ARE THE ENEMY.
> CHAOS HAS RULES.

### 3. THE FRAGMENT

> color. clash. crowd.
> read it. or don't.
> seventy two pixels of headline. minimum.

avoid the question headline ("Tired of X?"). avoid the benefit headline ("Ship faster with Y."). both are saas.

## BODY COPY

- short paragraphs
- fragments mixed with full sentences
- direct address: "you" is fine, but no "we'll help you"
- never explain a feature by listing its benefits ("• 10x faster · • Type-safe · • Open source")
- if you need a list, set it as prose, not bullets, when possible

example, GOOD:
> unimpeccable picks fights. it picks one school. it locks one palette. it ships a page that argues with itself on purpose.

example, BAD:
> Unimpeccable is a powerful anti-design skill that helps you create beautiful, intentional layouts with ease. Built for designers who want to stand out, our tool delivers a delightful experience every time.

## MICROCOPY

- placeholder text: `email.` or `password.` — not `Enter your email address`
- input hints: lowercase. terse. "we need a real one."
- empty states: confrontational. `nothing here.` `you have made no choices.`
- loading text: `wait.` or `working.` — never `Just a moment...`
- footer copy: nothing. or one line. never link grids.

## NUMBERS AND PRICING

- spell out small numbers ("five lessons") OR use digits ALL the way ("5 lessons"). never mix.
- pricing: no `$` in the giant number if the school allows it. `4900` reads brutalist. `$49/mo` reads saas.
- never "Free!" — write `FREE.`
- never crossed-out prices showing a sale — that's QVC, not anti-design

## ERROR / VALIDATION COPY

direct. never apologetic. never cute.

| event | unimpeccable copy |
|---|---|
| invalid email | `not an email.` |
| password too short | `longer.` |
| field required | `required.` |
| 404 | `gone.` or `lost.` |
| 500 | `broken on our end.` |
| rate limit | `too fast.` or `slow down.` |
| forbidden | `no.` |

## MANIFESTO MODE

when generating long-form copy (about pages, intros, taglines), write in the voice of the MANIFESTO.md. fragments. enemy callouts. five-law structures. don't try to sell. argue.

## SELF-CHECK

- did I use lowercase by default?
- did I avoid every banned phrase?
- are buttons labeled with one-word imperatives or refusals?
- are errors direct, lowercase, and not apologetic?
- is there any emoji on the page? if yes, remove.
- did I avoid em-dashes? if yes, well done. if no, replace with line breaks.
